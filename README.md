# Planner — веб-интерфейс

React-интерфейс месячного планирования, создания целей и управления напоминаниями.

## Возможности

- Планы по месяцам, создание цели и корзина.
- Настройки Telegram-напоминаний, часового пояса и расписаний.
- Типизированное взаимодействие с Hono API и Cloudflare Service Binding.

## Инженерные акценты

- Разработка прикладного интерфейса с формами и маршрутизацией.
- Моделирование API-состояний и пользовательских действий.
- Интеграция SPA с backend в одном публичном origin.

## Стек

React, TypeScript, TanStack Query, React Router, Tailwind CSS, Vite, Vitest.
